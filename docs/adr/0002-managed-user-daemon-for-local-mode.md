# 本地模式使用桌面管理的用户级守护进程

iMail Windows 桌面应用同时支持本地服务和远程服务模式。本地模式把与桌面版本匹配的服务程序随安装包发布，由桌面应用自动注册和管理为当前 Windows 用户的守护进程，使桌面 UI 退出后邮件同步仍可持续；远程模式暂停本机守护进程并连接用户部署的 Docker 服务实例。用户级守护进程避免了额外安装步骤和系统级权限，同时保留客户端与邮件服务的进程边界；代价是 Windows 桌面发布必须负责注册、升级、故障恢复和卸载。本地与远程实例保持独立数据源，不进行隐式同步、迁移或故障回退。原生 Linux 与 macOS 桌面构建不在当前支持范围。
